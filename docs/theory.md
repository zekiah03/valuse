# 価値観診断システム「Valuse」の理論的基盤
## 多次元価値観測定における統合的理論フレームワーク

---

## 概要

価値観は人間の行動・判断・幸福感の根本的規定因である。本論文は、価値観診断システム「Valuse」の理論的基盤を構築するため、シュワルツの基本的価値観理論（Schwartz, 1992, 2012）、マズローの拡張欲求階層理論（Maslow, 1943, 1969）、ロキーチの価値調査（Rokeach, 1973）、フランクルの実存的価値論（Frankl, 1946）、デシとライアンの自己決定理論（Deci & Ryan, 1985, 2000）、並びにピーターソンとセリグマンのVIA強み分類（Peterson & Seligman, 2004）を統合的に考察する。

これらの先行研究を踏まえ、本論文は以下を提案する：
1. **七次元価値観分類体系**とその理論的正当化
2. **改良マズロー対応マッピング**（超越欲求を含む五段階）
3. **価値観アーキタイプ理論**（七類型）
4. **価値観葛藤分析**（サーカンプレックスに基づく対立指数）
5. **改訂スコアリングアルゴリズム**

---

## 1. 序論

### 1.1 価値観とは何か

心理学・哲学・社会学の分野で長く研究されてきた「価値観」（values）とは、人が望ましいと判断する目標や状態についての信念であり、行動の選択、判断の基準、及び優先順位の形成に深く関与する認知的・動機的構造である（Schwartz, 1992）。価値観は個人の行動のみならず、集団・文化・社会の意思決定構造をも規定する超個人的な力を持つ。

価値観は以下の点で「態度」「好み」「性格」と区別される：

- **超状況的一般性**：特定の場面だけでなく、多様な文脈にわたって行動を方向づける
- **規範的要請性**：「〜すべき」という当為の感覚を伴う
- **優先順位的機能**：複数の選択肢・行動様式・人物・出来事を比較評価する基準として機能する

### 1.2 価値観診断の現代的意義

現代において価値観診断ツールへの需要は急増している。自己理解の深化、キャリア選択、対人関係の最適化、組織文化との適合性評価など、価値観のプロファイリングは多様な実用的文脈で活用されている。MBTI（Myers-Briggs Type Indicator）やBig Five性格検査が認知・行動スタイルを測定するのに対し、価値観診断は「何を大切にするか」という動機的核心を照射する。

しかし、既存のツールはしばしば単一の理論的枠組みに依拠し、価値観の多次元性を十分に捉えきれていないという限界を有する。本論文はこの限界を超えるため、複数の確立された理論を統合した新たなフレームワークを提案する。

### 1.3 本論文の目的と構成

本論文の目的は三点である：

1. 複数の価値観理論を統合した多次元価値観フレームワークを提案する
2. 七次元分類体系の各次元に対して理論的根拠を付与する
3. 価値観プロファイルの解釈のための規範的枠組み（アーキタイプ理論）を確立する

## 2. 先行研究レビュー

### 2.1 シュワルツの基本的価値観理論（1992, 2012）

Schwartz（1992）は、人間の価値観に関する最も包括的かつ実証的に検証された理論を提唱した。57か国以上での横断的研究を通じて、文化を超えて普遍的に存在する**10の基本的価値観**を同定した：

| 価値観 | 動機的目標 |
|--------|-----------|
| 自己決定 (Self-Direction) | 思考・行動における自律性・独立性 |
| 刺激 (Stimulation) | 新奇性・挑戦・人生の興奮 |
| 快楽 (Hedonism) | 感覚的快楽・個人的な楽しみ |
| 達成 (Achievement) | 社会的基準に照らした個人的成功 |
| 権力 (Power) | 社会的地位・威信・他者と資源への支配 |
| 安全 (Security) | 社会・関係・自己の安全・調和・安定 |
| 同調 (Conformity) | 規範・期待を侵害する行動の抑制 |
| 伝統 (Tradition) | 文化・宗教が体現する慣習への尊重・傾倒 |
| 博愛 (Benevolence) | 近しい他者の幸福の保全・増進 |
| 普遍主義 (Universalism) | 全人類・自然の理解・鑑賞・保護 |

#### サーカンプレックス構造

シュワルツの最重要な発見は、これら10価値観が**動機的葛藤と融和の関係**に基づく円環構造（サーカンプレックス）を形成することである。円環の対極に位置する価値観は動機的に相反し、隣接する価値観は共存可能である。

```
         普遍主義
    博愛       自己決定
  伝統           刺激
    同調        快楽
       安全   達成
           権力
```

四つの高次価値観（2012年改訂）：

- **変化への開放性** (Openness to Change)：自己決定・刺激・快楽
- **保守性** (Conservation)：同調・安全・伝統
- **自己増強** (Self-Enhancement)：達成・権力・（快楽）
- **自己超越** (Self-Transcendence)：普遍主義・博愛

この円環構造は、本フレームワークにおける**価値観葛藤分析**の理論的根拠をなす。

### 2.2 マズローの欲求階層理論とその拡張

Maslow（1943）が提唱した欲求階層理論は、人間の動機を五段階の階層として概念化した。低次の欲求が充足されると高次の欲求が顕在化するとされるが、現代の研究はこの厳格な順序性よりも**同時的並存**を支持する（Tay & Diener, 2011）。

| 段階 | 欲求 | 特徴 |
|-----|------|------|
| 1 | 生理的欲求 | 食・睡眠・呼吸など生存の基盤 |
| 2 | 安全欲求 | 身体・経済・健康・財産の安全 |
| 3 | 所属・愛情欲求 | 愛・友情・帰属・受容 |
| 4 | 承認欲求 | 自尊・達成・承認・地位 |
| 5 | 自己実現欲求 | 潜在能力の開花・意味の実現 |

**特筆すべき点**：Maslow（1969）は晩年に**第六段階「超越欲求」（Transcendence needs）**を付加した。超越欲求は自己の限界を超えた精神的成長・他者へのサービス・至高体験（peak experience）の追求を含む。これは研究者の間で長年見落とされてきたが、精神的価値観を扱う本フレームワークでは不可欠な段階である。

さらにマズローは欲求を二分類した：

- **欠乏欲求（D欲求 / deficiency needs）**：充足されていない状態への反応として生じる（安全・所属・承認）
- **存在欲求（B欲求 / being needs）**：成長・潜在能力の発現・意味の追求によって駆動される（自己実現・超越）

D欲求は充足されると動機力を失うが、B欲求は充足されるほど強化されるという非線形的性質を持つ。

### 2.3 ロキーチの価値調査（1973）

Rokeach（1973）は価値観を36項目に分類し、**終末価値観**（terminal values）と**手段的価値観**（instrumental values）に二分した。

- **終末価値観**：人生において達成すべき最終目標状態（例：真の友情、内なる調和、自由、知恵）
- **手段的価値観**：目標達成のための行動様式・性格特性（例：誠実さ、勤勉さ、想像力、愛情深さ）

この二元区分は本フレームワークにおける価値観の「深さ」の概念化に貢献する。道徳的・社会的価値観は終末価値観的性格を持ちやすく、経済的・個人的価値観は手段的価値観的性格を持ちやすい。

### 2.4 自己決定理論（Deci & Ryan, 1985, 2000）

Deci & Ryan（1985, 2000）の自己決定理論（SDT）は、人間の動機を外的調整から内的統合まで連続体として概念化する。三つの**基本的心理的欲求**の充足が心理的well-beingの根幹をなす：

1. **自律性**（Autonomy）：自分の意志で行動するという感覚
2. **有能感**（Competence）：環境に効果的に働きかける能力の感覚
3. **関係性**（Relatedness）：他者との温かな繋がりの感覚

SDTの観点から、本フレームワークの「個人的」価値観は自律性・有能感の内的充足に、「社会的」価値観は関係性欲求の充足に対応する。価値観診断は、ユーザーがどの基本的欲求を優先的に充足しようとしているかの間接的指標を提供する。

### 2.5 フランクルの実存的価値論（1946）

Frankl（1946）はアウシュビッツ体験に基づく実存的心理療法（ロゴセラピー）の文脈で価値観を**三類型**に分類した：

1. **創造価値**（Creative values）：行為・創造・貢献を通じて実現される価値。「世界に何を与えるか」
2. **体験価値**（Experiential values）：美・真理・愛など受動的体験を通じて実現される価値。「世界から何を受け取るか」
3. **態度価値**（Attitudinal values）：変えられない苦悩に対する態度を通じて実現される価値。「苦しみに対してどう立ち向かうか」

フランクルの枠組みは本フレームワークの「審美的」「精神的」価値観次元の理論的支柱として機能する。特に「態度価値」は精神的価値観の核心概念であり、外的条件に左右されない内的自由の価値を示す。

### 2.6 VIA強み分類（Peterson & Seligman, 2004）

Peterson & Seligman（2004）はポジティブ心理学の観点から普遍的な性格強みの分類体系VIA（Values in Action）を提案した。24の強みが六つの徳目に分類される：

| 徳目 | 含まれる強み | 対応価値観次元 |
|-----|------------|--------------|
| 知恵 (Wisdom) | 創造性・好奇心・判断力・向学心・洞察力 | 知的 |
| 勇気 (Courage) | 勇敢さ・粘り強さ・誠実さ・熱意 | 道徳的・個人的 |
| 人間性 (Humanity) | 愛情・親切心・社会的知性 | 社会的 |
| 正義 (Justice) | チームワーク・公平性・リーダーシップ | 道徳的・社会的 |
| 節制 (Temperance) | 許容力・謙虚さ・慎重さ・自制心 | 道徳的 |
| 超越性 (Transcendence) | 審美眼・感謝・希望・ユーモア・精神性 | 審美的・精神的 |

VIAの「超越性」徳目が審美的価値観と精神的価値観の両方にまたがることは、この二次元の深い理論的親縁性を示唆する。

## 3. 統合的七次元価値観フレームワーク

### 3.1 フレームワークの構築原則

本フレームワークは以下の三原則に基づいて構築される：

**原則A：理論的多元性**
単一理論への依存を避け、複数の確立された理論的枠組みを統合する。各次元は少なくとも二つの独立した理論的系譜によって正当化される。

**原則B：測定可能性**
各次元はリッカート尺度による自己報告測定が可能な、行動的・動機的内容を有する。抽象度が高すぎず、具体的行動や態度として顕在化する。

**原則C：文化的適切性**
日本文化特有の価値観表現（「和」「義理・人情」「恥と誇り」「もったいない」「間」の感覚）を理論的に包摂できる柔軟性を持つ。

### 3.2 七次元の詳細定義と理論的根拠

#### 次元１：道徳・倫理的価値観（Moral-Ethical Values）

**概念核**：正義・誠実・思いやり・責任という行動原則を、外的拘束ではなく内的規範として保持すること。

**理論的根拠**：
- シュワルツ：普遍主義（全人類への配慮・公正の追求）+ 博愛の規範的側面
- ロキーチ：終末価値「平等」「自由」、手段的価値「誠実さ」「責任感」
- VIA：正義徳目（公平性・チームワーク）+ 勇気徳目（誠実さ）
- SDT：関係性の道徳的次元（他者への配慮が関係性欲求の高次形態として機能）

**下位側面**：
1. **正義志向**：社会的不公正への感受性と変革衝動
2. **誠実性**：言行一致・約束遵守・透明性
3. **他者配慮**：共感・慈悲・利他的行動傾向

**日本文化との接点**：「義」の概念、「恩返し」の文化的義務感、「恥」を基盤とする行動規範

---

#### 次元２：社会的価値観（Social Values）

**概念核**：帰属・連帯・協調という関係的絆の中に生の意味と喜びを見出すこと。

**理論的根拠**：
- シュワルツ：博愛（近しい他者の幸福増進）+ 同調（集団規範の内面化）+ 伝統（世代を超えた絆の継続）
- SDT：関係性欲求の核心的充足（帰属感・受容感）
- VIA：人間性徳目（愛情・親切心・社会的知性）
- マズロー：所属・愛情欲求（第三段階）の価値観的表現

**下位側面**：
1. **家族・友人絆**：親密な対人関係の深化・維持
2. **コミュニティ参加**：集団・地域への貢献と帰属感
3. **協調・平等**：集団内の調和と公平な関係性の実現

**日本文化との接点**：「和」の精神、「空気を読む」集団感受性、「義理」による関係性維持

---

#### 次元３：個人的価値観（Personal-Autonomy Values）

**概念核**：自律・成長・自己決定という内的プロセスを通じた、固有の自己の実現。

**理論的根拠**：
- シュワルツ：自己決定（思考・行動の自律性）+ 達成（個人的成功の追求）
- SDT：自律性欲求（最も核心的な基本的欲求）+ 有能感欲求
- ロキーチ：終末価値「自由」「自尊心」「達成感」「幸福」
- マズロー：承認欲求（自己尊重側面）から自己実現欲求への橋渡し

**下位側面**：
1. **自律性**：自分の規範に基づく独立した意思決定
2. **成長志向**：現状を超えた自己開発への継続的動機
3. **内的充足**：外的報酬より内的満足を優先する傾向

**日本文化との接点**：「一国一城の主」という自立志向、近年若者世代の「自分らしさ」追求

---

#### 次元４：精神的・宗教的価値観（Spiritual-Religious Values）

**概念核**：物質を超えた次元に意味・超越・内なる平和を求め、存在の根本的な問いと向き合うこと。

**理論的根拠**：
- シュワルツ：伝統（精神的・宗教的慣習への傾倒）+ 普遍主義（宇宙・自然との繋がり感）
- フランクル：態度価値の核心（苦悩を意味に変換する精神的自由）
- マズロー：超越欲求（第六段階：至高体験・self-transcendence）、自己実現における「B価値」の最高表現
- VIA：超越性徳目（精神性・感謝・希望・畏敬）

**下位側面**：
1. **実存的意味**：「なぜ生きるか」という問いへの探求
2. **超越体験**：日常を超えた繋がり・一体感・至高体験
3. **内的平和**：不動の精神的安定・受容・存在への感謝

**日本文化との接点**：神道・仏教の融合的精神性、「もののあわれ」「禅」的静寂への親しみ、先祖崇拝

---

#### 次元５：知的価値観（Intellectual Values）

**概念核**：真理・知識・論理的探究を通じた世界の理解と、複雑な問いとの格闘に喜びを見出すこと。

**理論的根拠**：
- シュワルツ：自己決定の知的側面（理解・探究の自由）+ 刺激（知的挑戦による興奮）
- VIA：知恵の徳目全体（創造性・好奇心・判断力・向学心・洞察力）
- ロキーチ：終末価値「知恵」、手段的価値「論理的」「想像力豊か」
- SDT：有能感欲求の認知的充足（「わかった」感覚・習熟の喜び）

**下位側面**：
1. **認知的好奇心**：未知への探究衝動・学習の内発的動機
2. **分析的思考**：論理・証拠・批判的吟味を重んじる態度
3. **複雑性耐性**：単純な答えを求めず、曖昧さと共存できる能力

**日本文化との接点**：「道」の概念（茶道・剣道等における技術の哲学化）、「博識」への敬意

---

#### 次元６：審美的価値観（Aesthetic Values）

**概念核**：美・創造性・芸術的表現に深い感受性と情熱を持ち、美しいものを鑑賞・創造することで人生を豊かにすること。

**理論的根拠**：
- シュワルツ：刺激（芸術体験の感覚的・感情的覚醒）+ 自己決定の表現的側面（創造的自己表現）
- フランクル：体験価値の核心（美・音楽・自然・芸術による超越的受容）
- VIA：超越性徳目の「審美眼」（美と秀逸さへの畏敬）+ 知恵徳目の「創造性」
- マズロー：B価値（Being-values）における「美」「完全性」「豊かさ」「唯一性」

**下位側面**：
1. **審美的感受性**：美・洗練・調和への敏感な知覚
2. **創造的衝動**：表現・制作・発明への内的強迫
3. **感覚的豊かさ**：五感を通じた豊かな体験への欲求

**日本文化との接点**：「侘び寂び」「間（ま）」の美学、「道具」への精巧さへの崇拝、「歌舞伎・能・俳句」の美的伝統

---

#### 次元７：経済的・物質的価値観（Economic-Material Values）

**概念核**：安定・成功・物質的豊かさを人生の重要な基盤と捉え、経済的自由と効率的成果を追求すること。

**理論的根拠**：
- シュワルツ：安全（物質的安全基盤の確保）+ 権力（富・成功による社会的影響力）+ 達成（認められる成果の実現）
- ロキーチ：終末価値「豊かで快適な生活」「社会的承認」、手段的価値「向上心」「能力」
- マズロー：安全欲求（物質的安全）+ 承認欲求の外的側面（地位・名声）
- SDT：外的調整・取り込み（外的報酬・社会的評価に動機づけられる段階）

**下位側面**：
1. **経済的安定**：リスク回避・将来への備え・安定基盤の確保
2. **成功達成**：社会的に認められる成果・地位・キャリアの実現
3. **効率・実用性**：資源・時間の最適活用・コスト意識

**日本文化との接点**：「立身出世」の伝統的価値、バブル世代の物質的成功志向、「安心・安定」重視の集団的傾向

### 3.3 次元間の関係性モデル：価値観二次元空間

シュワルツの円環モデルに倣い、七次元は**動機的類縁性**に基づく二次元空間に配置される。

**軸１：超越志向 ↔ 物質志向**（Transcendence ↔ Materiality）
- 超越側：精神的・知的・審美的
- 物質側：経済的

**軸２：他者志向 ↔ 自己志向**（Other-Orientation ↔ Self-Orientation）
- 他者側：道徳的・社会的
- 自己側：個人的

```
                    ｜超越志向
                    │
          知的 ────精神的
         ╱    ╲   ╱    ╲
       審美的    ╳      審美的
         ╲    ╱   ╲    ╱
他者志向──道徳的───────個人的──自己志向
           ╲         ╱
            社会的  経済的
                  ╲╱
                   │
                   │物質志向
```

簡略配置図：

```
           超越
            ↑
     知的・精神・審美
            |
他者 ← 道徳・社会 | 個人 → 自己
            |
          経済的
            ↓
           物質
```

この二次元空間において、**対角線上に位置する次元ペア**が最も強い動機的葛藤を生じやすい。

### 3.4 価値観葛藤ペアの理論化

シュワルツの円環理論を援用し、本フレームワークにおける主要葛藤ペアを同定する。葛藤重みは理論的親縁性の逆数として設定する：

| 葛藤ペア | 葛藤の本質 | 重み |
|---------|----------|------|
| 経済的 ↔ 精神的 | 物質vs.超越：世俗的成功と霊的充足の優先順位 | 0.90 |
| 経済的 ↔ 道徳的 | 利己vs.利他：個人の利益と公共の善の優先順位 | 0.80 |
| 個人的 ↔ 社会的 | 自律vs.帰属：独立した自己と集団への埋め込みの均衡 | 0.75 |
| 経済的 ↔ 審美的 | 効率vs.美：結果の実用性と体験の質の優先順位 | 0.70 |
| 知的 ↔ 経済的 | 真理vs.有用性：知識の純粋追求と実践的成果の均衡 | 0.65 |
| 精神的 ↔ 社会的 | 孤独vs.繋がり：内的探求と外的関係性の時間的競合 | 0.50 |

**葛藤指数の算出**：
```
葛藤指数(A, B) = (score_A / 100) × (score_B / 100) × 葛藤重み(A, B)
```

葛藤指数が高い場合（例：0.5以上）、ユーザーは内的矛盾や意思決定の困難を経験しやすい可能性がある。このことを診断結果に反映することで、価値観の「統合課題」を可視化できる。

## 4. 改良マズロー対応マッピング

### 4.1 五段階モデルの採用

本フレームワークはMaslow（1943, 1969）の原典に立ち返り、**超越欲求を含む五段階モデル**を採用する。

| 段階 | 欲求名 | 主要次元 | 副次元 | 重み |
|-----|--------|---------|--------|-----|
| 1 | 安全欲求 | 経済的 | — | 経済的 × 1.00 |
| 2 | 所属欲求 | 社会的 | — | 社会的 × 1.00 |
| 3 | 承認欲求 | 個人的 | 道徳的 | 個人的 × 0.55 + 道徳的 × 0.45 |
| 4 | 自己実現欲求 | 知的 | 審美的・個人的 | 知的 × 0.40 + 審美的 × 0.35 + 個人的 × 0.25 |
| 5 | 超越欲求 | 精神的 | 道徳的・知的 | 精神的 × 0.60 + 道徳的 × 0.25 + 知的 × 0.15 |

### 4.2 各段階の改訂根拠

**安全欲求（Safety）**：経済的価値観との1対1対応を維持。物質的安全基盤の確保という動機が明確に合致する。

**所属欲求（Belonging）**：社会的価値観との1対1対応を維持。SDTの関係性欲求との整合性も高い。

**承認欲求（Esteem）**：承認には自己尊重（内的承認）と他者からの評価（外的承認）の二種がある。個人的価値観（内的）と道徳的価値観（倫理的自尊）を組み合わせることで、この二側面を捕捉する。

**自己実現欲求（Self-Actualization）**：マズロー原典における自己実現はBeing-Values（B価値）の実現を含む。知的探究・審美的体験・個人的成長の三軸で構成する。個人的価値観を25%含むのは、自己実現が自律的な自己展開を前提とするためである。

**超越欲求（Transcendence）**：Maslow（1969）が晩年に加えた段階で、自己を超えた全体への奉仕・至高体験・精神的一体感を含む。精神的価値観が主軸だが、普遍主義的な道徳的コミットメントと知的な世界理解も超越体験の基盤となる。

### 4.3 D欲求とB欲求の区分

診断結果の解釈において、マズロー段階を以下のように分類する：

- **D欲求段階**（安全・所属・承認）：欠乏への応答として動機づけられる
- **B欲求段階**（自己実現・超越）：充足そのものが新たな動機を生む成長的欲求

支配的段階がD欲求に属する場合、「現在何かが不足している」という感覚が行動を駆動している可能性を示唆する。B欲求段階の場合、「すでに満たされた基盤の上での成長」への志向を示す。

## 5. 価値観アーキタイプ理論

本フレームワークの中核的貢献として、**価値観アーキタイプ**（Value Archetypes）理論を提案する。アーキタイプとは、特定の価値観プロファイルが生み出す人格的傾向の原型であり、スコアを超えた「生き方の様式」を提示する。

### 5.1 アーキタイプの理論的基盤

心理学的アーキタイプの概念はユング（Jung, 1959）の集合的無意識論に起源を持つが、本フレームワークのアーキタイプはユング的な深層心理ではなく、**価値観の組合せパターンによる動機的プロトタイプ**として定義される。

各アーキタイプは以下の要素で構成される：
1. 支配的価値観次元（2〜3次元）
2. 核心的動機（生の根本的推進力）
3. 特徴的行動傾向
4. 理論的対応（シュワルツ・マズロー・VIA）
5. 典型的な強みと課題

### 5.2 七つのアーキタイプ

#### I. 守護者（The Guardian / 守護者）

**支配的価値観**：道徳的 + 社会的  
**動機核**：他者の保護と倫理的秩序の維持  
**特徴**：強い責任感・規範遵守・共同体への献身・正義への感受性  
**シュワルツ対応**：普遍主義 + 博愛 + 同調  
**マズロー段階**：所属欲求〜承認欲求（D欲求の充足と倫理的自尊の獲得）  
**VIA対応**：正義徳目（公平性・チームワーク）+ 勇気徳目（誠実さ）

**強み**：信頼性・責任感・集団の結束力の維持・倫理的指針の提示  
**成長課題**：規則への固執から生じる柔軟性の欠如・自己犠牲の過度化・変化への抵抗  
**生き方の様式**：「人は助け合って生きている」という確信のもと、共同体のために役立つことに喜びを見出す。不正を見逃せない正義感と、人々の絆を守ろうとする深い愛情が行動の源泉となる。

**アーキタイプ重みベクトル**：
```
道徳的=0.40, 社会的=0.40, 個人的=0.08, 精神的=0.05, 知的=0.04, 審美的=0.02, 経済的=0.01
```

#### II. 探求者（The Seeker / 探求者）

**支配的価値観**：知的 + 精神的  
**動機核**：真理と意味の徹底的な探究  
**特徴**：深い好奇心・哲学的思考・内省性・孤独への親和性・本質への問い  
**シュワルツ対応**：自己決定 + 刺激 + 普遍主義（超越的側面）

**強み**：深い洞察力・本質を見抜く力・学習への持続的動機・意味を見出す能力  
**成長課題**：現実世界との接続の困難・社会的孤立・観念的すぎる思考・知識と行動の乖離  
**生き方の様式**：「なぜ」という問いを止められない。知ることと理解することそのものに喜びを感じ、人生の意味という大きな問いを手放さない。孤独の中に豊かさを見出す。

### 5.3 アーキタイプ決定アルゴリズム

アーキタイプは**親和性スコア**（Affinity Score）の最大値によって決定される。

```
アーキタイプ親和性スコア(A) = Σ (weight_A[dim] × score[dim]) / 100
```

各次元の正規化スコア（0〜100）にアーキタイプの重みベクトルをかけた加重平均として算出する。最も高い親和性スコアを示すアーキタイプがユーザーの基本アーキタイプとなる。

**二次アーキタイプ**：スコア差が10ポイント以内の場合、「〜と〜の側面を併せ持つ」という複合的プロファイルを提示することを推奨する。

### 5.4 アーキタイプの解釈上の注意

アーキタイプはステレオタイプではなく、**可能性のプロトタイプ**として解釈されなければならない。以下の点を明示する：

1. アーキタイプは現在の価値観優先度を反映するものであり、固定的な「性格」ではない
2. すべての人はすべての次元の側面を持ち、アーキタイプはその現在の重心を示す
3. 価値観は意識的な実践によって変化・深化しうる

## 6. 質問設計の方法論（改訂版）

### 6.1 設計原則

#### 原則１：行動的アンカー（Behavioral Anchoring）
抽象的な価値観の記述より、具体的な行動・状況・選択への言及を優先する。

- 不適切：「正義を大切にしている」
- 適切：「不公平な場面では、不利益を受けても声を上げることが多い」

#### 原則２：現在志向（Present Orientation）
現在の自分の状態・傾向を測定する。過去の体験や未来の希望ではなく、現時点での価値的優先順位を問う。

#### 原則３：比較的中立語（Comparative Neutrality）
社会的望ましさバイアスを低減するため、一方的に「良い」とみなされる記述を避ける。

- 問題あり：「困っている人を必ず助けている」（社会的望ましさが高すぎる）
- 改善案：「困っている人を助けることは、自分の大切な責任だと思っている」

#### 原則４：多側面カバレッジ（Multi-facet Coverage）
各次元の下位側面（3側面）を各2問ずつ配置し、内容の偏りを防ぐ。6問構成の場合の理想的分布：

```
次元X (6問): 側面α (2問) + 側面β (2問) + 側面γ (2問)
```

#### 原則５：逆転項目の導入（Reverse Item Inclusion）
各次元に1〜2問の逆転項目（高スコアが低い価値志向を示す）を混在させ、黙従バイアス（すべてに同意してしまう傾向）を検出する。

### 6.2 現行42問の診断と改善点

現行質問セットは原則１・２・３をおおむね満たしているが、以下の点で改善余地がある：

**問題点**：
1. 逆転項目が存在しない（黙従バイアスの検出不可）
2. 一部の質問が社会的望ましさの影響を受けやすい（例：mo3「困っている人を助けることは責任」）
3. 審美的価値観の「創造的衝動」側面が弱い（ae5のみ）
4. 精神的価値観の「超越体験」側面が具体性に欠ける

**改善推奨**：
- 各次元に逆転項目を1問追加（計7問追加、49問体制）
- または現行の特定問を逆転形式に書き換え

## 7. 改訂スコアリングアルゴリズム

### 7.1 カテゴリスコアの算出

```
raw_score(category) = Σ answer_scores / n_questions
normalized_score(category) = round(((raw_score - 1) / 4) × 100)
```

逆転項目がある場合：
```
reversed_score(item) = 6 - answer_score
```

### 7.2 マズロー段階スコアの算出

```
safety_score       = economic_score
belonging_score    = social_score
esteem_score       = round(personal × 0.55 + moral × 0.45)
selfAct_score      = round(intellectual × 0.40 + aesthetic × 0.35 + personal × 0.25)
transcendence_score = round(spiritual × 0.60 + moral × 0.25 + intellectual × 0.15)
```

### 7.3 支配的マズロー段階の決定

単純な最大値ではなく、**段階的充足モデル**を採用する。高次段階で高スコアを示す場合でも、低次段階が著しく低い場合は「充足の課題」として解釈する。

支配的段階 = 最高スコアの段階（ただし、それより低次の段階スコアが40以下の場合は警告フラグを立てる）

### 7.4 アーキタイプスコアの算出

```
affinity(archetype) = Σ (weight[archetype][dim] × score[dim]) / 100
```

主アーキタイプ = argmax(affinity)  
副アーキタイプ = 2番目に高いaffinityのアーキタイプ（差が15以内の場合のみ）

### 7.5 葛藤指数の算出

主要6葛藤ペアに対して：
```
tension(A, B) = (score_A / 100) × (score_B / 100) × weight(A, B)
```

高葛藤ペア（tension > 0.35）をユーザーに「統合的成長の課題」として提示する。

西洋心理学に基づく価値観理論を日本の文化的文脈に適用する際、以下の点を考慮する：

**集団主義的文脈**：シュワルツの研究は日本が「同調」「伝統」「博愛」を相対的に高く評価することを示している。本フレームワークの「社会的」「道徳的」次元はこの傾向を適切に捕捉する。
